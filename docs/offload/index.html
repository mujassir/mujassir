  • iCloud-only items flagged so you don’t waste a move.

Clouds

Accounts you already pay for

Connect Google Drive, OneDrive and Dropbox. Tokens stay in this iPhone’s Keychain — this device only. Offload only uses its own folder (or files it created), never the rest of your drive.

  • Live quota and combined free space.
  • New phone? Library syncs via your private iCloud; reconnect each cloud once.
  • Home Screen and Lock Screen widgets for a quick space check.
